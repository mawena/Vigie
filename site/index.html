Être prévenu sur le téléphone avant que le serveur casse

Disque qui se remplit, service tombé, conteneur arrêté, certificat qui expire, sauvegarde ratée, site qui ne répond plus : Vigie le voit et vous envoie une notification. Sans Prometheus, sans Grafana, sans root : un binaire d'une dizaine de Mo de mémoire.

Sur Ubuntu 24.04 (amd64) :

curl -fsSL https://apt.mawena.cloud/installer.sh | sudo sh -s -- vigie

Le script ajoute le dépôt APT signé de mawena (dépôt unique de tous ses paquets) puis installe le paquet ; les commandes qu'il lance sont détaillées plus bas.

Ce que surveille Vigie

La machine

Remplissage des disques, mémoire disponible, charge par cœur, températures quand il y a des capteurs.

Les services

Unités systemd en échec ou arrêtées, conteneurs Docker arrêtés ou « unhealthy », machines virtuelles libvirt.

Les sites

Code de réponse et temps de réponse HTTP(S), jours restants des certificats TLS, résolution DNS.

Les sauvegardes

Âge du fichier le plus récent d'un dossier : une sauvegarde nocturne ratée se voit le matin.

Des alertes qui ne harcèlent pas

ntfy, Telegram ou e-mail. Durée minimale avant d'alerter, alertes groupées, rappel espacé, message de retour à la normale.

Sans root

Service systemd utilisateur, lecture seule : Vigie regarde, il ne touche à rien.

Installer

Pour Ubuntu 24.04 et les distributions Debian équivalentes, sur processeur amd64. Une fois le dépôt ajouté, sudo apt update && sudo apt upgrade apporte les nouvelles versions.

  1. Ajouter la clé qui signe le dépôt :

    sudo curl -fsSLo /usr/share/keyrings/mawena-depot.gpg https://apt.mawena.cloud/mawena-depot.gpg

  2. Ajouter le dépôt (apt.mawena.cloud, dépôt unique des paquets de mawena) :

    sudo curl -fsSLo /etc/apt/sources.list.d/mawena-depot.sources https://apt.mawena.cloud/mawena-depot.sources

  3. Installer :

    sudo apt update && sudo apt install mawena-depot vigie

  4. Configurer et démarrer, en tant qu'utilisateur (pas root) :

    mkdir -p ~/.config/vigie && vigie config-exemple > ~/.config/vigie/vigie.toml
vigie etat
vigie test-alerte
systemctl --user enable --now vigie

En dernier recours, le paquet .deb est joint à chaque release GitHub ; il dépend de mawena-depot, à prendre sur apt.mawena.cloud.
